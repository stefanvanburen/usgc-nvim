1. Introduction                                            *usgc-introduction*

Neovim port of the U.S. Graphics Company color schemes:
https://github.com/usgraphics/usgc-themes

All credit for the original color schemes goes to U.S. Graphics Company:
https://usgraphics.com/

==============================================================================
2. Requirements                                            *usgc-requirements*

- Neovim 0.8+
- 'termguicolors' enabled (these themes use true color only, no cterm
  fallback)

==============================================================================
3. Installation                                            *usgc-installation*
>lua
    vim.opt.termguicolors = true
    vim.pack.add({ 'https://github.com/stefanvanburen/usgc-nvim' })
    -- e.g.
    vim.cmd.colorscheme('usgc-highk')
<

==============================================================================
4. Themes                                                        *usgc-themes*

    PART NUMBER  THEME NAME        DESCRIPTION
    5200-010     usgc-highk        White scheme
    5200-020     usgc-reticle      Dark scheme
    5200-030     usgc-polyimide    Amber scheme
    5200-040     usgc-epitaxy      Magenta scheme
    5200-050     usgc-metalgate    Cyan scheme

                                                                  *usgc-highk*
`usgc-highk` (5200-010)      White scheme. High dielectric constant.

                                                                *usgc-reticle*
`usgc-reticle` (5200-020)    Dark scheme. Photomask for lithography.

                                                              *usgc-polyimide*
`usgc-polyimide` (5200-030)  Amber scheme. Heat-resistant polymer.

                                                                *usgc-epitaxy*
`usgc-epitaxy` (5200-040)    Magenta scheme. Crystal layer growth.

                                                              *usgc-metalgate*
`usgc-metalgate` (5200-050)  Cyan scheme. Metal gate transistor.

==============================================================================
